================================================================================
           SUPER SIMPLE TEAM SETUP GUIDE: ZERO TO WORKING UNITY PROJECT
================================================================================

Welcome to the team! Follow this step-by-step checklist in order.
Do not skip steps, and take your time. Everything here is free.

--------------------------------------------------------------------------------
PART 1: FREE STUDENT PERKS & ACCOUNTS
--------------------------------------------------------------------------------

Step 1: Create a GitHub Account
  1. Go to https://github.com and sign up using your university / school email address.
  2. Confirm your email by clicking the verification link they send to your inbox.

Step 2: Claim GitHub Student Developer Pack (Free Pro Perks)
  1. Go to https://education.github.com/pack
  2. Click "Sign up for Student Developer Pack".
  3. Submit proof of enrollment (student ID card or school email).
  4. Once approved, your account gets free GitHub Pro and extra developer tools.

Step 3: Create a Unity Account & Claim Unity Student Plan
  1. Go to https://unity.com and create an ID using your school email.
  2. Visit https://unity.com/products/unity-student
  3. Click "Apply Now" (this links with your verified GitHub Student status).
  4. This gives you Unity Pro/Student features and removes splash screens.

--------------------------------------------------------------------------------
PART 2: DOWNLOAD THE REQUIRED TOOLS
--------------------------------------------------------------------------------

Step 4: Install Git (The tool that downloads the team's project files)
  - Windows:
      1. Download Git from https://git-scm.com/download/win
      2. Run the installer and keep clicking "Next" with the default settings.
  - Mac:
      1. Open the Terminal app (press Command + Space, type Terminal).
      2. Type: git --version
      3. If not installed, your Mac will automatically pop up a box asking to install developer tools. Click "Install".

Step 5: Install .NET SDK (Helps your code editor understand Unity scripts)
  1. Go to https://dotnet.microsoft.com/download
  2. Download the latest .NET SDK for your operating system (Windows or macOS).
  3. Run the installer to completion.

Step 6: Install Visual Studio Code (Code Editor)
  1. Download VS Code from https://code.visualstudio.com/
  2. Open VS Code, click the Extensions icon on the left (the 4 squares), and install:
     - "C# Dev Kit"
     - "Unity" extension by Microsoft

Step 7: Install Unity Hub & Unity 6
  1. Go to https://unity.com/download and install "Unity Hub".
  2. Open Unity Hub, click "Sign in" at the top right, and log in with your Unity account.
  3. Go to the "Installs" tab on the left.
  4. Click "Install Editor" and look for Unity 6 (Version 6000.x / Unity 6).
     *CRITICAL*: Everyone on the team MUST use the exact same Unity 6 version so files don't break.

--------------------------------------------------------------------------------
PART 3: PULLING THE PROJECT FROM GITHUB
--------------------------------------------------------------------------------

Step 8: Clone / Pull the Repository
  1. Ask the project owner to invite your GitHub username to the team repository.
  2. Open your terminal (Mac) or Command Prompt / Git Bash (Windows).
  3. Navigate to where you want the project folder to live, for example:
       cd Desktop
  4. Clone the project using:
       git clone <PASTE_GITHUB_REPO_URL_HERE>
  5. Enter the project folder:
       cd <REPO_FOLDER_NAME>

Step 9: Opening the Project in Unity Hub
  1. Open Unity Hub.
  2. Click the "Projects" tab on the left.
  3. Click the "Add" button (or "Add project from disk").
  4. Select the project folder you just cloned.
  5. Click on the project to open it. (The first time you open it, Unity may take 5–10 minutes to compile everything. Be patient!).

--------------------------------------------------------------------------------
PART 4: VERIFYING YOUR PROJECT SETTINGS & INPUT
--------------------------------------------------------------------------------

Step 10: Check the Input System Setting
  If you open the project and see warnings or errors about Input:
  1. In Unity, go to: Edit -> Project Settings.
  2. Select "Player" on the left menu.
  3. Scroll down on the right to "Active Input Handling".
  4. Ensure it is set to "Both" (or "Input Manager (Old)").
  5. If Unity asks to restart, click "Yes".

Step 11: Test the Scene
  1. In the bottom "Project" panel, go to Assets -> Scenes.
  2. Double-click the main scene (e.g., "SampleScene").
  3. Hit the "Play" button at the top center.
  4. You should see:
     - The typewriter text intro on a dark screen.
     - The character lying down and getting up under the spotlight.
     - WASD controls to walk around.

--------------------------------------------------------------------------------
PART 5: TEAM COLLABORATION GOLDEN RULES (READ CAREFULLY!)
--------------------------------------------------------------------------------

Rule 1: Always PULL before you work
  Before you touch anything in Unity, open your terminal in the project folder and run:
       git pull
  This prevents conflicting changes.

Rule 2: Never delete .meta files
  Every single file in the Assets folder has a companion file ending in ".meta".
  Unity uses these files to remember links, textures, and scripts. Always commit both the file AND its .meta file!

Rule 3: Save before you commit
  Before sharing your work with Git:
  - In Unity, press Ctrl + S (Cmd + S on Mac) to save the scene.
  - Click File -> Save Project.
  - Then run:
       git add .
       git commit -m "Brief description of what you changed"
       git push
